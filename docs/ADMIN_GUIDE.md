# دليل الأدمن (صفحتان)

## 1) استلام الطلب وتجهيزه
1. افتح `/admin.html` وسجّل الدخول (رمز الإيميل أو Google).
2. تبويب **الطلبات**: الجديد يظهر في أعلى القائمة بلون مميّز مع إشعار صوتي (يمكن إيقافه). استخدم الفلاتر والبحث (رقم الطلب/الاسم/الموبايل/الفرع).
3. اضغط الطلب لفتح التفاصيل: بيانات العميل، المنتجات، الإجمالي، سجل الأحداث.
4. غيّر الحالة **بالترتيب فقط**: جديد ← قيد التجهيز ← تم التواصل ← مؤكد ← تم التسليم. «إلغاء» متاح قبل التسليم ويُرجع المخزون تلقائيًا. كل تغيير يُسجَّل باسمك ووقته.

## 2) التواصل والتأكيد
- **واتساب:** زر يفتح محادثة جاهزة برقم الطلب والإجمالي، ويُسجَّل أنه تم التواصل.
- **إيميل:** «إرسال إيميل تأكيد» يرسل رسالة منسقة باسم الشركة (يُعرض تلقائيًا بعد تحويل الحالة إلى «مؤكد»).
- **المنتجات:** إضافة/تعديل السعر والمخزون والألوان والمقاسات، إخفاء المنتج دون حذفه، رفع صورة (تُضغط تلقائيًا).
- **أكواد الخصم** و**رسائل التواصل** و**التصدير CSV** من التبويبات.

## 3) عند حدوث خطأ
| المشكلة | الحل |
|---|---|
| «غير مصرح» | الحساب غير مضاف في `admins` — أضفه بأمر SQL في `SETUP.md` |
| «لا يمكن نقل الطلب لهذه الحالة» | الحالة التالية فقط مسموحة؛ حدّث الصفحة وراجع سجل الطلب |
| لم يصل إيميل | تحقق من مفتاح Resend ونطاق المرسل وسجل الدالة في Supabase ← Edge Functions ← Logs؛ تواصل بواتساب كبديل |
| لا يظهر طلب جديد لحظيًا | حدّث الصفحة؛ تأكد أن Realtime مفعّل لجدول `orders` (يتم بالـmigration 0002) |
| العميل لا يستلم رمز الدخول | راجع مجلد الرسائل غير المرغوبة، ثم إعدادات SMTP في Supabase |
